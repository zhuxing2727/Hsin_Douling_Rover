# 自动战斗脚本整理

本目录保存三个角色自动战斗脚本的原始文本，以及对脚本行为和运行依赖的整理说明。

- `卜灵.txt`：`Douling` 角色脚本与修改需求上下文。
- `雷主.txt`：`Rover` 角色脚本，包含光主、风主和暗主形态分派。
- `心.txt`：`Hsin` 角色脚本与修改需求上下文。
- `脚本理解.md`：对三个脚本的流程、状态、切人策略、依赖和风险的说明。

这些 `.txt` 文件保留了原始内容，包含 Markdown 代码围栏、说明文字和 BaseChar 参考链接，因此它们是脚本设计记录，不是可以直接导入运行的纯 Python 模块。实际运行时需要将对应代码放入项目的角色模块，并满足 `src.char.BaseChar`、`src.Labels`、任务对象及视觉识别接口等依赖。

## Git

当前目录已初始化为 Git 仓库。首次提交包含原始脚本和理解文档。后续可以使用：

```powershell
git status
git add .
git commit -m "更新自动战斗脚本整理"
```
