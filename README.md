# 自动战斗脚本整理

本目录保存三个角色自动战斗脚本的原始文本，以及对脚本行为和运行依赖的整理说明。

- `卜灵.txt`：`Douling` 角色脚本与修改需求上下文。
- `雷主.txt`：`Rover` 角色脚本，包含光主、风主和暗主形态分派。
- `心.txt`：`Hsin` 角色脚本与修改需求上下文。
- `脚本理解.md`：对三个脚本的流程、状态、切人策略、依赖和风险的说明。
- `队伍循环轴.md`：固定 1/2/3 号位和启动轴、循环轴的执行规格。
- `rotation_axis.py`：共享的启动轴/循环轴状态机和按键适配层。
- `卜灵.py`、`雷主.py`、`心.py`：三个固定位置的角色类。
- `check_rotation.py`：语法和轴顺序检查脚本。

这三个 `.txt` 文件保留了原始内容，包含 Markdown 代码围栏、说明文字和 BaseChar 参考链接，因此它们是脚本设计记录。新增的 `.py` 文件按固定轴实现，但仍需放入实际项目的角色模块，并满足 `src.char.BaseChar`、任务对象及视觉识别接口等依赖。

运行检查：

```powershell
python check_rotation.py
```
