# 自动战斗脚本整理

## 使用说明

1. 心 1 号位，卜 2 号位，雷主 3 号位。
2. 入局以卜为主控角色，并尽量在怪物旁边开怪。
3. 作者使用的共鸣效率参考值为：心 118，卜 210，雷主 130。
4. 如果遇到角色长时间普攻，通常是因为脚本设置为不放大招、先普攻积攒技能；可以提升对应角色的共鸣效率来改善体验。
5. 如果遇到部分衔接问题，可以提交 GitHub issue。

本目录保存三个角色自动战斗脚本的原始文本，以及对脚本行为和运行依赖的整理说明。

- `rotation_axis.py`：轴规格的独立检查参考实现。
- `卜灵.py`、`雷主.py`、`心.py`：按实际项目调度方式编写的三个固定位置角色类。每个文件都可单独粘贴，不依赖外部轴模块。
- `check_rotation.py`：语法、动作接口和轴顺序检查脚本。
